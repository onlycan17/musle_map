# 근육 학습 지도 개인정보 처리방침

시행일: 2026년 9월 3일

근육 학습 지도(이하 “앱”)는 해부학 학습 노트를 기기 안에서만 처리합니다.

## 처리하는 정보

앱은 사용자가 직접 입력하거나 표시한 다음 정보를 처리합니다.

- 학습 노트 이름
- 학습 완료 근육과 관심 근육 표시
- 학습 포인트와 기록 시각

## 이용 목적

해부학 학습 내용을 주제별로 저장하고 이전 학습 기록과 비교하거나 복원하는 기능에만 사용합니다.

## 저장, 전송 및 공유

- 모든 정보는 사용자의 기기에만 저장됩니다.
- 개발자 서버로 전송하거나 제3자에게 공유하지 않습니다.
- 광고 또는 이용 분석 목적으로 사용하지 않습니다.
- 앱은 계정 생성, 외부 서버 동기화, 광고 및 분석 SDK를 사용하지 않습니다.

## 보관 및 삭제

학습 노트는 사용자가 앱을 사용하는 동안 기기에 보관됩니다. 앱을 삭제하면 함께 삭제되며, 앱 안의 초기화 기능으로 표시를 지울 수 있습니다.

## 아동의 개인정보

앱은 만 13세 미만 아동을 대상으로 설계되지 않았으며 개발자가 개인정보를 수집하지 않습니다.

## 앱의 목적

이 앱은 인체 근육의 위치와 명칭을 익히기 위한 교육용 도구입니다.
