# PRD - 근육 학습 지도

## 목적

인체 정면·후면 근육 도식에서 근육의 위치와 명칭을 익히고 주제별 학습 기록을 기기에 남기는 해부학 교육 앱.

## 사용자

- 인체 해부학 입문자
- 근육의 위치와 명칭을 반복 학습하는 학생
- 도식 위에 개인 학습 주석을 남기고 싶은 사용자

## 핵심 사용자 가치

1. 학습 완료 근육과 관심 근육을 색으로 빠르게 구분
2. 주제별 학습 기록을 저장하고 이전 기록과 비교
3. 정면/후면을 나누어 세부 근육 위치를 반복 확인

## 핵심 기능

- 학습 노트 생성 및 전환
- 정면/후면 근육 지도
- 파란색 학습 완료 표시
- 빨간색 관심 근육 표시와 학습 포인트
- 학습 기록 저장, 비교 및 복원
- 로컬 자동 저장

## 비목표

- 서버 계정 동기화
- 개인 신체 정보 기록
- 개인 맞춤형 권고
- 사진 촬영 기반 자동 인식

## 성공 기준

- 사용자가 근육을 탭해 파란색/빨간색 상태를 1초 이내에 표시할 수 있음
- 앱 재실행 후 학습 노트별 표시가 유지됨
- 현재 표시를 학습 기록으로 저장하고 이전 기록과 비교할 수 있음
- `flutter analyze`, `flutter test`, `flutter build apk --debug` 통과
