# PRD - Muscle Map

## 목적

운동 평가나 통증 체크 과정에서 인체 정면/후면 근육 도식에 약한 근육과 풀어야 할 근육을 직접 표시하고, 사용자별 변화 기록을 로컬에 남기는 모바일 앱.

## 사용자

- 트레이너, 재활 운동 코치
- 물리치료 또는 해부학 학습자
- 운동 후 약화/통증 부위를 시각적으로 기록하고 싶은 사용자

## 핵심 사용자 가치

1. 약한 근육과 통증/과활성 근육을 색으로 빠르게 구분
2. 사용자별 기록을 저장해 상담이나 운동 처방 전후 변화를 비교
3. 정면/후면을 나누어 세부 근육 위치를 반복 확인

## 핵심 기능

- 사용자 등록 및 사용자 전환
- 정면/후면 근육 지도
- 파란색 약화 표시
- 빨간색 통증/과활성 표시와 원형 포인트
- 현재 상태 히스토리 저장
- 과거 기록 비교 및 복원
- 로컬 자동 저장

## 비목표

- 서버 계정 동기화
- 의학적 진단 자동화
- 근육별 운동 추천
- 사진 촬영 기반 자동 인식

## 성공 기준

- 사용자가 근육을 탭해 파란색/빨간색 상태를 1초 이내에 표시할 수 있음
- 앱 재실행 후 사용자별 표시 상태가 유지됨
- 현재 상태를 히스토리로 저장하고 과거 상태와 비교할 수 있음
- `flutter analyze`, `flutter test`, `flutter build apk --debug` 통과
