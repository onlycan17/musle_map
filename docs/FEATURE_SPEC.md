# 기능 명세 - Muscle Map

## 화면 구성

- 헤더: 앱 제목, 현재 뷰, 전체 표시 수, 캘리브레이션, 초기화 메뉴
- 사용자 바: 사용자 선택, 사용자 정보 수정, 사용자 추가, 현재 상태 기록, 히스토리 보기
- 뷰 전환: 정면/후면 전환
- 표시 도구: 약한 근육(파란색 채움), 풀어야 할 근육(빨간색 채움), 통증 포인트(빨간색 점)
- 본문: 인체 근육 이미지 + 클릭 가능한 근육 오버레이
- 하단 정보 바: 마지막으로 누른 표시 영역 상태, 현재 도구, 표시 수
- 태블릿 가로 화면: 좌측에 헤더/사용자/도구/정보 패널을 세로로 배치하고, 우측에 인체 표시 영역을 크게 유지
- iPad 방향 지원: iPhone은 세로 중심으로 유지하고, iPad는 세로/가로 방향을 모두 지원

## 인터랙션

| 동작 | 결과 |
| --- | --- |
| 사용자 추가 | 로컬에 새 사용자 프로필 생성 |
| 사용자 정보 수정 | 현재 선택된 사용자의 이름과 선택 입력 생년월일 저장 |
| 사용자 선택 | 해당 사용자에게 저장된 파란색/빨간색/통증점 표시 복원 |
| 표시 도구 선택 | 이후 탭할 표시 방식 변경 |
| 표시 영역 탭 | 파란색 또는 빨간색 채움 도구로 표시, 같은 색을 다시 탭하면 해제 |
| 통증 포인트 도구로 신체 부위 탭 | 색을 채우지 않고 탭한 위치에 빨간 원형 점 추가, 가까운 점을 다시 탭하면 삭제 |
| 현재 상태 기록 | 현재 사용자 상태를 히스토리 스냅샷으로 저장 |
| 히스토리 비교 | 과거 기록을 옅은 외곽선으로 현재 상태와 함께 표시 |
| 히스토리 복원 | 과거 기록을 현재 상태로 불러오기 |
| 초기화 | 현재 뷰 또는 전체 뷰의 표시 제거 |

## 시각 스펙

- 약한 근육: 파란색 채움 `Color(0xAA2577D9)`, 외곽선 `Color(0xFF124E9F)`
- 풀어야 할 근육: 빨간색 채움 `Color(0xBBD84A3A)`
- 통증 포인트: 탭한 좌표에 빨간색 원형 점과 흰색 테두리
- 히스토리 비교: 과거 표시를 옅은 외곽선으로 표시
- 배경 도식: `assets/images/body_front.png`, `assets/images/body_back.png`
- 배경 도식 바깥은 투명 처리
- 클릭/채색은 별도 픽셀 마스크 기준으로 처리하여 경계선 내부에만 표시
- 통증 포인트는 동일한 픽셀 마스크 위의 신체 영역에만 추가

## 표시 영역 데이터

- 전면/후면 표시 영역은 사용자 제공 라인 도식의 검은 경계선을 기준으로 자동 분할
- 기존 상세 근섬유 이미지용 좌표와 손수 작성한 폴리곤은 사용하지 않음
- `body_front_regions.png`, `body_back_regions.png`의 고유 색상 픽셀을 표시 영역 ID로 사용
- 선 위나 바깥 배경처럼 마스크가 투명한 곳은 탭해도 표시하지 않음

## 데이터 모델

- `UserBodyProfile`: 사용자 이름, 선택 입력 생년월일, 생성/수정 시각, 현재 표시 상태, 히스토리 목록
- `BodySnapshot`: 저장 시점, 정면/후면별 표시 상태와 통증 포인트 상태
- `MuscleMarkType`: `weak` 또는 `release`
- `BodyMarkMap`: `BodyView`별 근육 id와 표시 상태 매핑
- `BodyPainPoint`: 통증 포인트의 기준 이미지 좌표와 생성 시각

## 저장 방식

- `shared_preferences`에 JSON 문자열로 저장
- 앱 재실행 시 마지막 선택 사용자와 표시 상태를 복원
- 생년월일은 숫자 8자리 또는 `YYYY-MM-DD`로 입력하고 `YYYY-MM-DD` 형식으로 저장하며 입력하지 않아도 됨
- 히스토리는 사용자별 최대 30개까지 유지

## 비기능

- 네트워크 없이 로컬 동작
- 전면/후면 기준 좌표계는 배경 이미지와 픽셀 마스크 크기를 기준으로 유지
- 클릭 외 영역은 이미지 알파 마스크 기준으로 무시
- 840px 이상이면서 가로가 세로보다 넓은 화면에서는 태블릿 가로 레이아웃으로 전환
