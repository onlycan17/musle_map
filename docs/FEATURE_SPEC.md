# 기능 명세 - 근육 학습 지도

## 화면 구성

- 헤더: 앱 제목, 현재 뷰, 전체 표시 수, 캘리브레이션, 초기화 메뉴
- 학습 노트 바: 노트 선택, 이름 수정, 노트 추가, 학습 기록 저장·보기
- 뷰 전환: 정면/후면 전환
- 표시 도구: 학습 완료 근육(파란색), 관심 근육(빨간색), 학습 포인트(빨간색 점)
- 본문: 인체 근육 이미지 + 클릭 가능한 근육 오버레이
- 하단 정보 바: 마지막으로 누른 표시 영역 상태, 현재 도구, 표시 수
- 태블릿 가로 화면: 좌측에 헤더/사용자/도구/정보 패널을 세로로 배치하고, 우측에 인체 표시 영역을 크게 유지
- iPad 방향 지원: iPhone은 세로 중심으로 유지하고, iPad는 세로/가로 방향을 모두 지원

## 인터랙션

| 동작 | 결과 |
| --- | --- |
| 학습 노트 추가 | 로컬에 새 주제별 학습 노트 생성 |
| 학습 노트 수정 | 현재 선택한 학습 노트 이름 저장 |
| 학습 노트 선택 | 해당 노트의 근육 표시와 학습 포인트 복원 |
| 표시 도구 선택 | 이후 탭할 표시 방식 변경 |
| 표시 영역 탭 | 파란색 또는 빨간색 채움 도구로 표시, 같은 색을 다시 탭하면 해제 |
| 학습 포인트 도구로 도식 탭 | 탭한 위치에 원형 주석 추가, 가까운 점을 다시 탭하면 삭제 |
| 학습 기록 저장 | 현재 학습 표시를 기록으로 저장 |
| 학습 기록 비교 | 이전 기록을 옅은 외곽선으로 현재 표시와 함께 표시 |
| 학습 기록 복원 | 이전 기록을 현재 표시로 불러오기 |
| 초기화 | 현재 뷰 또는 전체 뷰의 표시 제거 |

## 시각 스펙

- 학습 완료 근육: 파란색 채움 `Color(0xAA2577D9)`, 외곽선 `Color(0xFF124E9F)`
- 관심 근육: 빨간색 채움 `Color(0xBBD84A3A)`
- 학습 포인트: 탭한 좌표에 빨간색 원형 점과 흰색 테두리
- 학습 기록 비교: 이전 표시를 옅은 외곽선으로 표시
- 배경 도식: `assets/images/body_front.png`, `assets/images/body_back.png`
- 배경 도식 바깥은 투명 처리
- 클릭/채색은 별도 픽셀 마스크 기준으로 처리하여 경계선 내부에만 표시
- 학습 포인트는 동일한 픽셀 마스크 위의 도식 영역에만 추가

## 표시 영역 데이터

- 전면/후면 표시 영역은 사용자 제공 라인 도식의 검은 경계선을 기준으로 자동 분할
- 기존 상세 근섬유 이미지용 좌표와 손수 작성한 폴리곤은 사용하지 않음
- `body_front_regions.png`, `body_back_regions.png`의 고유 색상 픽셀을 표시 영역 ID로 사용
- 선 위나 바깥 배경처럼 마스크가 투명한 곳은 탭해도 표시하지 않음

## 데이터 모델

- `UserBodyProfile`: 학습 노트 이름, 생성/수정 시각, 현재 표시, 학습 기록 목록
- `BodySnapshot`: 저장 시점, 정면/후면별 근육 표시와 학습 포인트
- `MuscleMarkType`: `weak` 또는 `release`
- `BodyMarkMap`: `BodyView`별 근육 id와 표시 상태 매핑
- `BodyPainPoint`: 학습 포인트의 기준 이미지 좌표와 생성 시각

## 저장 방식

- `shared_preferences`에 JSON 문자열로 저장
- 앱 재실행 시 마지막 선택 학습 노트와 표시를 복원
- 학습 기록은 노트별 최대 30개까지 유지

## 비기능

- 네트워크 없이 로컬 동작
- 전면/후면 기준 좌표계는 배경 이미지와 픽셀 마스크 크기를 기준으로 유지
- 클릭 외 영역은 이미지 알파 마스크 기준으로 무시
- 840px 이상이면서 가로가 세로보다 넓은 화면에서는 태블릿 가로 레이아웃으로 전환
